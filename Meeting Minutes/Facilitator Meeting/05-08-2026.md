## Discussion
### Topic 1: Project Management
- The facilitator explained the overall expectations for managing the capstone project.
- GitHub should be used as the central platform to manage all project documentation and source code.

### Topic 2: Project Documentation
- The team should maintain comprehensive project documentation throughout the project.
- Required documentation includes:
  - Team guidelines (e.g., roles, ethics, and team expectations).
  - A detailed step-by-step development log documenting project progress.
  - Communication records, including meeting minutes.
- The step-by-step development log should include screenshots where appropriate and document troubleshooting processes and solutions.

### Topic 3: Team Organisation
- Three team members will rotate the Team Lead role throughout the project.
- Responsibility for recording meeting minutes will also rotate among team members to ensure shared ownership of project documentation.
- Team members are encouraged to contribute consistently to project documentation and communication records.

### Topic 4: Project Planning
- The first deliverable is due in **Week 5**.
- The deliverable should include:
  - MVP definition.
  - Project planning.
  - The selected development methodology (e.g., Agile or Waterfall) with justification.

### Topic 5: Client Collaboration
- The team should align project expectations with the client throughout the development process.
- If changes to the project scope are required, the team should evaluate the pros and cons of possible approaches before discussing and agreeing on changes with the client.

### Topic 6: Communication
- The team should maintain clear records of project communication.
- Meeting minutes should be documented and stored in GitHub as part of the project documentation.
